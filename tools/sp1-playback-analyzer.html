SP-1 Playback Analyzer

Plug the SP-1 in, connect, press PLAY on the device. This listens to the diagnostic console, differences the counters as they arrive, and says which failure mode the numbers match. It only ever reads the port — it never sends a byte, so it cannot disturb playback.

Per stem — which one is failing

A single column moving is a per-stem fault: that one track drops while the other three play on. All four moving together is an ordinary shared stall.

Counters are cumulative, so every figure here is a difference between consecutive samples — which means the capture has to be running while the song is. A capture taken after playback stopped shows identical lines and zero deltas; this tool now says so instead of showing a clean page. rduswin is already windowed by the firmware (read-and-clear); rdusmx is a sticky maximum since boot. On build st42 and later STEMRD is a per-read average over the print window (n= reads), not the single most recent read.
