SP-1 Playback Analyzer

Plug the SP-1 in, connect, press PLAY on the device. This listens to the diagnostic console, differences the counters as they arrive, and says which failure mode the numbers match. It only ever reads the port — it never sends a byte, so it cannot disturb playback.

This browser has no Web Serial. Use desktop Chrome or Edge. If you are already in Chrome and seeing this, the page was probably opened in a way that blocks it — from the folder containing this file run python3 -m http.server 8000 and open http://localhost:8000/sp1-playback-analyzer.html.

Close the companion app's connection first — the SP-1 has one serial port and it carries both the console and the upload protocol, so only one page can hold it at a time.
